Обновлено: 06.10.2026, после доводки V5 (П1–П17). Этот файл — сводка «что есть сейчас и что
устарело». Подробности по каждой версии — `CHANGELOG.md`, правила работы — `CLAUDE.md`.

## Ждёт решения владельца (не делать без «ок»)

1. **Миграция БД 00007 + деплой Core** (промокоды, акции тарифов, `POST /v1/subscriptions` → 402
   без оплаты). Порядок: миграция → Core → админка. До деплоя: промокоды в приложении отвечают
   ошибкой, раздел «Промокоды» в админке пишет, что нужен деплой; выбор тарифа в приложении
   уже не создаёт подписку (заглушка «обратитесь к администрации»).
   Внимание: сейчас на боевом Core любой вошедший пользователь может сам активировать
   публичный тариф без оплаты через `POST /v1/subscriptions` (так делала кнопка «Выбрать» в
   1.3.0) — деплой закрывает это.
2. Публикация Android (следующий номер 58) — только через `release.sh` после «публикуй».
3. Редизайн ПК по списку паритета (ниже) — после «ок».
4. Из CHANGELOG 1.3.0: «`DirectTLSLabel` у mirror-узла — нужен деплой Core» — проверить,
   выкачено ли (не проверялось в этой сессии).
5. **Дубли устройств** (каждый вход в аккаунт занимал слот подписки). В коде исправлено
   (06.10): приложения шлют `install_id` (постоянный ID установки, не стирается при выходе;
   на Android — в no-backup хранилище), Core по нему возвращает то же устройство
   (`devices.fingerprint`, миграция не нужна). Нужны: деплой Core (идёт вместе с п. 1) и выпуск
   приложений; старые версии приложений продолжат плодить дубли, пока их не обновят. Чистка
   дублей у ~12 пользователей (отзыв лишних устройств в БД) — только после деплоя и «ок»
   владельца, иначе дубли появятся снова. Сервер по одинаковому имени+платформе не склеиваем:
   два одинаковых телефона одного аккаунта получили бы один ID устройства.
6. **ПК 32/64 бит.** Flutter для Windows собирает только x64 и ARM64 — 32-битной сборки быть не
   может. Установщик уже пускает только на 64-битную Windows (`ArchitecturesAllowed=x64compatible`;
   на 32-битной — стандартное сообщение Inno Setup). Варианты на решение владельца: понятное своё
   сообщение в установщике/на сайте; нативная ARM64-сборка (нужна ARM-машина для сборки).

## Как проверять без телефона

- `cd wavebreak-mobile && flutter test` (130 тестов), `flutter analyze`.
- Стенд скриншотов: `flutter test test_screens --update-goldens` → PNG в
  `test_screens/out/<язык>/<размер>/` (не в git). Фильтры `WB_SHOTS`, `WB_SIZES`, `WB_SCALES`,
  `WB_LANG=ru,tr`. Падает на переполнениях раскладки. Шейдер сферы там не работает.
- Сфера: `flutter test test_screens/sphere_perf_test.dart` — время записи кадра и сравнение
  пикселей с эталоном.
- Core: `go test ./...`; интеграционные — с `WAVEBREAK_TEST_DATABASE_URL` (на этой машине нет
  PostgreSQL, Docker не поднимался).
- Общий пакет: `cd wavebreak-shared/wavebreak_links && dart test` (48).
- Админка: на этой машине нет PHP — тесты `wavebreak-admin/tests` не запускались.

## Паритет с ПК (делать после «ок» владельца)

Применимо к `wavebreak-pc` из доводки V5:
1. Каталог серверов (место → протоколы) и две точки переключения — шапка и «Серверы».
2. Настройки: 6 разделов на общих компонентах, «Помощь», токены нейтральных поверхностей.
3. Экран подписки: тарифы из Core с акциями, промокод, `PlanPurchase` вместо
   `createSubscription` (ПК сейчас тоже активирует тариф напрямую → после деплоя Core получит 402).
4. Сторонние подписки: разбор уже общий (`wavebreak_links`), нужен перенос контроллера
   (заголовки, интервал, секции) и пометки «не поддерживается» для sing-box (`TunnelEngine.singBox`:
   XHTTP, KCP).
5. Экран блокировки V5 (на Windows — без биометрии, только PIN).
6. Переводы экранов, которых нет на ПК, и тест полноты переводов.
7. Редизайн V5 в целом (сфера, волны, стекло) — отдельная большая работа; на ПК пока старый вид.
Не переносится: плитка в шторке, уведомление VPN Android, адаптация под старые телефоны.

## Устарело — не опираться

- Кнопки «Сменить сервер/протокол» в уведомлении VPN, `LocationPickerActivity`, выпадающий список
  в шапке, список локаций внизу главной, кнопка «Попробовать другой протокол» — удалены (П3b).
- Вкладка «Логи» в «Метриках» — удалена; экспорт журнала — в «Поддержке».
- `POST /v1/subscriptions` как «покупка» — выключено по умолчанию (402 `PAYMENT_REQUIRED`).
- В памяти/старых заметках: «ветка `main`/`app` актуальна» — нет, только `app-main-sync`.
- Тестовые сборки «с тем же номером, что установлен» — нет: каждая тестовая сборка занимает
  новый номер (`rel.dart take android <код>`).
