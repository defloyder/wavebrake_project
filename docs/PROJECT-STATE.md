# WAVEBREAK — состояние проекта (читать в начале сессии)

Обновлено: 12.10.2026 — в ветке (не выпущено, на устройствах не проверено): страницы с блоком
сверху и строками у пальца, единые уведомления, «Поделиться» = ссылка `/v1/sub` для Happ,
разбор чужих подписок, кнопки сервера/протокола в уведомлении VPN, отмена теста скорости,
исправление «выкидывает со всех устройств» (приложения + Core), Xiaomi-фон, ТВ на Xray-only.
Опубликованы по-прежнему **Android 1.3.2 (61)** и **Windows 1.0.13 (29)**. **Core на сервере
расходится с git** (п. 0), **сайт на сервере расходится с git** (п. 0б), **в `main` 26 коммитов
коллеги, которых нет в `app-main-sync`** (п. 0в). Подробности — `CHANGELOG.md` («Не выпущено»),
правила — `CLAUDE.md`. Обновляйте этот файл в конце каждой большой работы.

### Общий код Android / Windows / TV

С 07.10 интерфейс (`lib/features`, `lib/core/theme`, `lib/core/i18n`, `lib/core/errors`,
`services/core_api`, `services/custom_servers`, `server_catalog`, `live_metrics`,
`personal_locations`) **один и тот же** в `wavebreak-mobile` и `wavebreak-pc`: правьте в
`wavebreak-mobile` и копируйте файл в `wavebreak-pc`. Отличия ПК, которые нельзя затирать:
- `wavebreak-pc/lib/app/app.dart` (трей, закрытие чужих VPN), `main.dart`, `app_env.dart`;
- `services/vpn/*` кроме `server_catalog`/`live_metrics` (sing-box, восстановление),
  `services/update/update_service.dart` и `windows_update_installer.dart`,
  `features/settings/updates_screen.dart` (Inno Setup);
- `core/i18n/app_strings.dart` = мобильный + 5 строк трея (`trayConnect`, `trayDisconnect`,
  `trayOpen`, `trayQuit`, `closedOtherVpns`) — после копирования вернуть их;
- `services/vpn/personal_locations.dart`: `engine = TunnelEngine.singBox`;
- `live_metrics.dart` на ПК — с веткой Windows (счётчики sing-box через Clash API);
- `features/settings/support_screen.dart` — с веткой «Сохранить как» для Windows;
- тесты ПК: `third_party_subscription_test.dart` (TUIC на sing-box работает) и
  `i18n_completeness_test.dart` (исключение `startup_error.dart`) отличаются.
Сообщения пользователю — только `showNotice` / `showToast` (`features/shared/notice.dart`, карточка
вверху); `SnackBar` не использовать. Страницы со строками — `AnchoredPage` / `SettingsPage(hero:)`
(`features/shared/anchored_page.dart`): строки внизу, блок сверху, открываются с верха.
Стенд скриншотов есть в обоих проектах (`test_screens`, ПК — 1200×800; ТВ — мобильный с
`--dart-define=WAVEBREAK_TV=true`, 960×540).

## Ждёт решения владельца (не делать без «ок»)

0. **Core на сервере ≠ git.** 06.10 в 14:46 на боевой сервер выкачен Core, которого нет ни в
   одной ветке: отдельная БД для персональных данных (`internal/store/pii.go`,
   `migrations_pii/00001_pii_users.sql`, правки `config.go`, `cmd/*/main.go`, `Dockerfile`),
   склейка дублей устройств по имени+платформе (`device_dedupe_integration_test.go`), почта
   (`recipient_domain_test.go`), имена ссылок (`link_name_test.go`). Наш Core **не выкачен** —
   он бы это затёр. Порядок: коллега пушит свой Core в `app-main-sync` → сводим (промокоды,
   `install_id`, `x-hwid`, вход по QR) → тесты → миграции → деплой (раздел 9
   `docs/RELEASE-PROCESS.md`, сверка `sha256` исходников на сервере).
0б. **Сайт** — сведён 12.10: коллега запушил сайт с сервера в `main` (6fb66bf), он перенесён в
   `app-main-sync` (915b0ae) + мини-анимация превью и без двойного `wavebreak-horizon.css`.
   **На сервер анимация не выкладывалась** — после «ок» владельца. Тесты сайта на машине
   сборки не запускаются (нет PHP, Docker нельзя — ломает VPN владельца).
0в. **`main` ≠ `app-main-sync`.** Пробное слияние 12.10: **31 конфликт** — админка 15,
   мониторинг/nginx 8, Core 4 (`config.go`, `auth.go`, `server.go`, `redisstore`), нода 2
   (`config.go`, `runtime/xray.go`), `.gitignore`, бриф ПК. Многие — файлы, добавленные в обеих
   ветках независимо. Сводить вместе с коллегой, до любого деплоя Core/админки/ноды из нашей
   ветки. Коллега продолжает пушить в `main` (сайт, бриф, `a84ad5d` нода) — просьба пушить в
   `app-main-sync` (CLAUDE.md).
1. **Миграция БД 00007 + деплой Core** (промокоды, акции, `POST /v1/subscriptions` → 402 без
   оплаты) — после п. 0. На боевом Core всё ещё можно самому активировать публичный тариф без
   оплаты (кнопкой из 1.3.0 или запросом) — деплой закрывает.
2. **Лимит устройств для ссылки-подписки** (в git, ждёт деплоя): `/v1/sub/<id>` регистрирует
   каждое приложение на каждом устройстве по `x-hwid` (Happ, v2RayTun, Hiddify) в слотах
   подписки; сверх лимита — строка «⛔ Превышен лимит устройств»; без ID устройства —
   «приложение не поддерживается» (`WAVEBREAK_SUB_REQUIRE_HWID`, по умолчанию вкл. — пользователи
   v2rayNG останутся без серверов: решить при деплое). Ключи, уже вынутые из приложений,
   работают дальше — полностью закроют только ключи на устройство (не сделано).
3. **Вход по QR на ТВ** (в git, ждёт деплоя): `/v1/auth/device-login/*`, `/v1/me/device-login/*`.
   Приложения 1.3.2 / 1.0.13 уже умеют подтверждать («Аккаунт → Войти на другом устройстве»),
   ТВ-приложение — показывать QR; до деплоя ТВ пишет «вход по QR пока недоступен» и предлагает
   почту.
4. **Дубли устройств.** На сервере — склейка коллеги по имени+платформе; в git — `install_id`
   (приложения с 1.3.1 / 1.0.12 шлют). При сведении оставить оба: сначала `install_id`, без
   него — имя+платформа. Чистка старых дублей (~12 пользователей) — после деплоя и «ок».
5. **WAVEBREAK Lite (32 бит)** — проверить на настоящей 32-битной Windows 10, потом выложить.
6. **Android TV** — проверить на настоящем ТВ (пульт, VPN, вход по почте; QR — после деплоя);
   решить, раздавать ли APK на сайте (отдельный файл, свой канал обновлений не сделан).
7. Из CHANGELOG 1.3.0: «`DirectTLSLabel` у mirror-узла — нужен деплой Core» — проверить.
8. **Выкидывает со всех устройств (12.10, в git, Core ждёт деплоя).** Причина найдена по базе:
   при повторе refresh-токена Core отзывал **все** сессии аккаунта (`reuse_detected`, 17 раз с
   25.09). Приложения больше не повторяют обновление токена при 502/503 (в ветке, выйдет с
   ближайшим релизом); Core: повтор в течение 2 мин — не кража, настоящая кража отзывает только
   цепочку устройства (`store.go RotateRefreshToken`, тест `refresh_retry_integration_test.go`
   **не запускался**: на машине владельца Docker ломает VPN Happ — не запускать).
9. **Xiaomi / Redmi / POCO:** VPN «не грузит после сна, пока не откроешь приложение» — заморозка
   фона MIUI/HyperOS. В приложении есть строки «Экономия батареи: без ограничений» и
   «Автозапуск» (Настройки → Подключение); владельцу и другу выставить их.
10. **Обновление на MIUI / Android 10 у друга:** у кого стоит версия до 1.3.1, исправления
   установщика не работают (код установки — у старой версии) — один раз поставить APK с сайта.
11. **Хранить данные устройств у пользователя** (пожелание владельца 12.10): решения нет.
   Лимит устройств считает сервер — ему нужен хотя бы идентификатор установки; имя и модель
   можно не хранить на сервере (показывать из приложения) — обсудить вместе с ПД-базой коллеги.
