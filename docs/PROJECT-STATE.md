# WAVEBREAK — состояние проекта (читать в начале сессии)

Обновлено: 06.10.2026 вечер — опубликованы Android 1.3.1 (58) и Windows 1.0.12 (27); Core на
сервере расходится с git (см. «Ждёт решения», п. 0). Этот файл — сводка «что есть сейчас и что
устарело». Подробности по каждой версии — `CHANGELOG.md`, правила работы — `CLAUDE.md`.

## Ждёт решения владельца (не делать без «ок»)

0. **Core на сервере ≠ git.** 06.10 в 14:46 на боевой сервер выкачен Core, которого нет ни в
   одной ветке: отдельная БД для персональных данных (`internal/store/pii.go`,
   `migrations_pii/00001_pii_users.sql`, правки `config.go`, `cmd/*/main.go`, `Dockerfile`),
   склейка дублей устройств по имени+платформе (`device_dedupe_integration_test.go`), почта
   (`recipient_domain_test.go`), имена ссылок (`link_name_test.go`). Поэтому наш Core
   (промокоды 00007, `install_id`) **не выкачен** — он бы это затёр. Порядок: коллега пушит
   свой Core в `app-main-sync` → сводим с промокодами/`install_id` → тесты → миграции →
   деплой (по разделу 9 `docs/RELEASE-PROCESS.md`, сверка `sha256` исходников на сервере).
1. **Миграция БД 00007 + деплой Core** (промокоды, акции тарифов, `POST /v1/subscriptions` → 402
   без оплаты) — после п. 0. Порядок: миграция → Core → админка. До деплоя: промокоды в
   приложении отвечают «пока недоступны», раздел «Промокоды» в админке пишет, что нужен деплой;
   выбор тарифа в 1.3.1 уже не создаёт подписку (заглушка «обратитесь к администрации»).
   Внимание: на боевом Core любой вошедший пользователь всё ещё может сам активировать
   публичный тариф без оплаты через `POST /v1/subscriptions` (так делала кнопка «Выбрать» в
   1.3.0) — деплой закрывает это.
2. Редизайн ПК по списку паритета (ниже) — после «ок».
3. Из CHANGELOG 1.3.0: «`DirectTLSLabel` у mirror-узла — нужен деплой Core» — проверить,
   выкачено ли.
4. **Дубли устройств.** Сейчас на сервере работает склейка коллеги по имени+платформе (тот же
   телефон после выхода/входа слот не занимает; минус — два одинаковых телефона одного аккаунта
   станут одной записью). В git — точный способ: приложения (с 1.3.1 / 1.0.12, и Lite) шлют
   `install_id` (постоянный ID установки; на Android — в no-backup хранилище), Core по нему
   возвращает то же устройство (`devices.fingerprint`, миграция не нужна); старый Core отвечает
   400 — приложения повторяют без поля. При сведении с Core коллеги оставить оба: сначала
   `install_id`, без него — имя+платформа. Чистка старых дублей (~12 пользователей) — после
   деплоя и «ок».
5. **WAVEBREAK Lite (32 бит).** Проверить на настоящей 32-битной Windows 10 (UAC, вход,
   подключение REALITY/Direct/Hysteria2, закрытие); потом — ссылка на сайте и выкладка
   (в `release.sh` Lite пока нет). Подробно — `wavebreak-lite/README.md`.

  `test_screens/out/<язык>/<размер>/` (не в git). Фильтры `WB_SHOTS`, `WB_SIZES`, `WB_SCALES`,

  PostgreSQL, Docker не поднимался).
- Общий пакет: `cd wavebreak-shared/wavebreak_links && dart test` (48).
- Админка: на этой машине нет PHP — тесты `wavebreak-admin/tests` не запускались.

## Паритет с ПК (делать после «ок» владельца)

Применимо к `wavebreak-pc` из доводки V5:
1. Каталог серверов (место → протоколы) и две точки переключения — шапка и «Серверы».
2. Настройки: 6 разделов на общих компонентах, «Помощь», токены нейтральных поверхностей.
3. Экран подписки: тарифы из Core с акциями, промокод, `PlanPurchase` вместо
   `createSubscription` (ПК сейчас тоже активирует тариф напрямую → после деплоя Core получит 402).
4. Сторонние подписки: разбор уже общий (`wavebreak_links`), нужен перенос контроллера
   (заголовки, интервал, секции) и пометки «не поддерживается» для sing-box (`TunnelEngine.singBox`:
   XHTTP, KCP).
5. Экран блокировки V5 (на Windows — без биометрии, только PIN).
6. Переводы экранов, которых нет на ПК, и тест полноты переводов.
7. Редизайн V5 в целом (сфера, волны, стекло) — отдельная большая работа; на ПК пока старый вид.
Не переносится: плитка в шторке, уведомление VPN Android, адаптация под старые телефоны.

  в шапке, список локаций внизу главной, кнопка «Попробовать другой протокол» — удалены (П3b).
- Вкладка «Логи» в «Метриках» — удалена; экспорт журнала — в «Поддержке».
- `POST /v1/subscriptions` как «покупка» — выключено по умолчанию (402 `PAYMENT_REQUIRED`).
- В памяти/старых заметках: «ветка `main`/`app` актуальна» — нет, только `app-main-sync`.
- Тестовые сборки «с тем же номером, что установлен» — нет: каждая тестовая сборка занимает
  новый номер (`rel.dart take android <код>`).
