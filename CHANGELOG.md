# Changelog

## Android 1.1.9.4 (versionCode 30)

- Значок обновления в настройках и push-уведомление появляются сами, без «Проверить обновления»: проверка при запуске, при каждом возврате в приложение, каждые 10 минут и через минуту после неудачной; в фоне (приложение закрыто) — каждый час вместо 6 часов. Сначала московское зеркало, сайт — запасной.
- Откат — на 1.1.9.3 (versionCode 31).

## Android 1.1.9.3 (versionCode 28)

- Служебные запросы приложения (вход, подписка, локации, трафик) идут через Москву (dl.wavebreak.com.tr/core → сервер в Турции), напрямую в Турцию — запасной путь. Операторы тормозили прямые запросы к турецкому IP: секции долго грузились, висело «показаны сохранённые данные». VPN-трафик по-прежнему идёт только через выбранную локацию.
- Пинг Hysteria2 в секциях снова показывается — настоящий замер по UDP до самой Hysteria (раньше TCP-замер для неё был невозможен).
- Hysteria2: новый UDP-порт каждые 5–10 с (из 1.1.9.2) — обрывы на Альфа-Мобайл (Билайн) устранены.
- Отправка лога в Telegram открывает Telegram отдельным приложением.
- Откат — на 1.1.9.2 (versionCode 29).

## Android 1.1.9.2 (versionCode 26)

- Обновления скачиваются с докачкой: если соединение оборвалось или «зависло» на 15 с, загрузка продолжается с того же места, а не начинается заново; недокачанный файл сохраняется и после закрытия приложения.
- Зеркало загрузок в Москве (dl.wavebreak.com.tr): российский IP, который операторы не тормозят; основной сайт — запасной вариант.
- APK под архитектуру телефона (arm64 / armeabi-v7a) — примерно втрое меньше универсального.
- Подготовка к маскированной Hysteria2 (salamander + смена портов) — включится на сервере после открытия UDP-портов хостером.
- Откат — на 1.1.9.1 (versionCode 27).

## Android 1.1.9.1 (versionCode 24)

- Секции локаций показываются сразу из сохранённого, свежий список подтягивается в фоне (раньше при каждом запуске ждали до трёх запросов к серверу).
- Direct-TLS: соединения переиспользуются (мультиплексирование) — новое соединение ~350 мс вместо ~800 мс (замер на пилоте); сайты и файлы в Telegram открываются быстрее.
- DNS: знакомые сайты отвечают из кэша, обновление в фоне.
- Автовыбор канала срабатывает быстрее: канал, который «подключился», но не пропускает трафик (например, Hysteria2 на операторах, режущих UDP), заменяется за ~10–12 с; результаты проверок пишутся в диагностический лог.
- Откат — на 1.1.9 (versionCode 25).

## Android 1.1.9 (versionCode 22) · Windows 1.0.2 (build 5)

### Работа на любом операторе (Android)
- Автовыбор канала: если выбранный протокол не подключается или подключается, но трафик не идёт (3 проверки через туннель за ~13 с), приложение само переключается на следующий канал той же локации (Hysteria2 / Direct-TLS / VLESS). Рабочий канал запоминается отдельно для мобильной сети и Wi-Fi и в следующий раз пробуется первым.
- DNS идёт через туннель, а не через оператора (операторы подменяют ответы — из-за этого часть сайтов не открывалась).
- «Российские сайты напрямую» (Настройки → Подключение, по умолчанию включено): российские сервисы открываются без VPN — быстрее и без блокировок по зарубежному IP; заблокированные СМИ и трекеры идут через VPN.
- Hysteria2: BBR, увеличенные окна приёма, keep-alive каждые 10 с. На сервере — BBR standard вместо conservative, подбор MTU, Hysteria больше не перезапускается без изменений в пользователях.

### Поддержка
- Почта поддержки wavebreak.support@gmail.com и 6 готовых обращений (нет подключения, скорость, подписка и оплата, устройства и «Поделиться», вход, другое) с автоматически подставленными данными для поддержки.

### Windows
- sing-box останавливается при закрытии приложения (раньше держал сеть, и другие VPN, например Happ, не подключались); остатки после сбоя убираются при запуске.
- Меньше обрывов: туннель не перезапускается из-за появления собственного сетевого адаптера и одиночных медленных проверок.
- Вкладка «Настройки → Обновления» с откатом на предыдущую версию.
- Тест скорости переверстан под окно ПК, без прокрутки.

### Откат
- Android — на 1.1.8 (versionCode 23), Windows — на 1.0.1 (build 6).

## Android 1.1.8 (versionCode 20) · Windows 1.0.1 (build 3)

### Подключение и стабильность
- Вход больше не «зависает»: обновление токена выполняется один раз для всех запросов и идёт мимо общего перехватчика; новый токен сразу хранится в памяти, запись в хранилище ключей ограничена по времени (баг 1).
- «Нет интернета» показывается только когда устройство действительно офлайн; если недоступен сервер — отдельное сообщение. Вместо плашки — короткое уведомление о смене сети.
- Повторный запуск приложения сразу пускает внутрь по сохранённому профилю, проверка сессии идёт в фоне.
- Android: движок переживает смену сети без разрыва туннеля, проверка обновлений в фоне (WorkManager), таймер подключения не сбрасывается при перезапуске интерфейса (баги 1, 2, 4, 8).
- Задержка выбранной подключённой локации измеряется через сам туннель — одинаково для всех протоколов, включая Hysteria2 (Android — движок, Windows — Clash API sing-box) (баг 12).

### Доступ и подписка
- Каждый аккаунт получает собственный ключ доступа от сервера вместо общего зашитого в приложение; трафик считается по подписке пользователя (баг 10).
- Трафик меньше 1 ГБ показывается в МБ, обновляется раз в минуту при подключении; единицы — двоичные ГБ.
- Состояние «подписка закончилась, 7 дней на продление» с предупреждением.
- Сервер API — core.wavebreak.com.tr (напрямую, без CDN).
- Протоколы: VLESS REALITY, Direct-TLS, Hysteria2; на Android — через Xray-core.

### Поделиться и QR (баги 11, 15)
- «Поделиться» у своей подписки показывает персональный QR-код (действует 72 часа) с лимитами: устройства и общий трафик.
- Сканирование только внутри рамки; отсканированный код добавляется сразу.
- Лимит устройств проверяется на сервере: при исчерпании — «Достигнут лимит устройств». Устройство получателя видно владельцу в «Устройствах», удаление освобождает место и убирает секцию у получателя.
- Полученная подписка — отдельная секция с названием тарифа владельца, без CDN, её нельзя переслать дальше.
- В каждой секции — трафик и число устройств; карточка на главной показывает подписку выбранной локации.
- Windows: кнопки сканера нет (камера не поддерживается) — код вставляется ссылкой.

### Интерфейс и безопасность
- Убран тест пинга под кнопкой подключения (баг 5) и пункт «Авто (самый быстрый)» (баг 6).
- PIN — это и есть блокировка; смена и удаление PIN требуют текущий PIN; биометрия только вместе с PIN; повторная блокировка после 1 минуты в фоне (баг 7).
- PIN из 4 цифр больше не «молчит» на экране блокировки: проверка не зависит от зависаний хранилища ключей, неверный PIN показывается сразу.
- «О приложении» → «Веб-сайт»: https://wavebreak.com.tr (баг 13).
- Название своей секции — по тарифу (например, WAVEBREAK Fleet).

### Обновления (баг 14)
- Откат на одну предыдущую версию, если сервер его опубликовал: Android — «Настройки → Обновления», Windows — «О приложении». Повторный откат — только после следующего обновления.
