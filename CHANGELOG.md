# Changelog

## Windows 1.0.9 (build 21) — опубликована 2026-10-01, откат 1.0.8 (build 22, из ff4d3a8)

- Исправлено: у части пользователей VPN отключался через ~8 секунд после подключения на любом протоколе (отзыв 01.10, два ПК). Проверка «чужого VPN» срабатывала на любой адаптер с похожим именем (Radmin VPN, OpenVPN, драйвер TAP/wintun), даже если он стоял на ПК постоянно. Теперь отключаемся, только если чужой VPN появился *после* нашего подключения; имя адаптера пишется в лог. Не проверено на ПК коллеги.
- Новое: при подключении приложение само закрывает другие VPN- и прокси-клиенты, которые перехватывают маршрут или системный прокси (Happ — приложение и служба HappService, v2rayN, Hiddify, NekoBox, Throne, Clash, Karing, AmneziaVPN, Outline, Proton VPN, NordVPN, ExpressVPN, Surfshark, Windscribe, Psiphon, Lantern), и снимает системный прокси, если он указывал на этот компьютер (Happ оставлял 127.0.0.1:10809 — браузеры переставали работать). Пользователю показывается, что закрыто. Не трогаются: WireGuard, корпоративные VPN (Cisco, GlobalProtect, Forti), Radmin/Hamachi/ZeroTier/Tailscale. Не проверено на устройстве.
- Новое: иконка в области уведомлений («Показать скрытые значки»): с зелёной точкой — VPN подключён, серая — отключён; подсказка — состояние и локация; левый клик открывает окно, правый — меню: подключить/отключить, выбор локации (выбор сразу подключает), открыть, выйти (с отключением VPN). Не проверено на устройстве. Сделано на Win32 в раннере, без новых зависимостей.

- Откат — на 1.2.4.2 (versionCode 50).
- Не проверено на устройстве (фикс шторки — проверить на Redmi Note 9 Pro после публикации).

## Windows 1.0.8 — cloak для Hysteria2 (проверена на ПК 01.10 18:15; build 17 — тестовая, опубликована build 19)
- Проверено на ПК владельца (без Happ): `cloak-client-proxy` заворачивает трафик на 45.15.41.3:443, 54 соединения через Hysteria, таймаутов нет. - Трафик прокси к серверу идёт мимо туннеля (правило `direct` на IP сервера) — иначе TUN sing-box заворачивал бы его сам в себя.
- Приложение сообщает Core `hysteria-cloak` и начинает получать турецкую Hysteria.
- Откат — на 1.0.7 (build 18).

## Android 1.2.4 (versionCode 42) — cloak для Hysteria2 (опубликована 2026-10-01)

- Турецкая Hysteria2 работает через cloak (маскировка «формы» трафика: случайный размер пакетов, паузы, фоновый шум) — против обрывов Hysteria на мобильных сетях (Альфа). На сервере перед Hysteria стоит cloak-relay (UDP 443).
- Ссылки с `cloak=1` идут через клиент Hysteria в мосте (apernet + cloak), остальные Hysteria2-ссылки — через Xray, как раньше. Для cloak-ссылки smart routing (российские сайты напрямую) не применяется.
- Приложение сообщает Core `hysteria-cloak`; Core отдаёт cloak-ссылку только таким приложениям (старые версии и Windows не видят нерабочую локацию). В `/v1/sub` ссылка идёт с `cloak=1`.
- Проверено: мост 1.2.4 с `cloak=1` через живой relay из России — 75 с, 15/15 запросов, ~117 мс.
- Откат — на 1.2.3 (versionCode 43).

- Автовыбор канала: если выбранный протокол не подключается или подключается, но трафик не идёт (3 проверки через туннель за ~13 с), приложение само переключается на следующий канал той же локации (Hysteria2 / Direct-TLS / VLESS). ## Android 1.1.8 (versionCode 20) · Windows 1.0.1 (build 3)

### Подключение и стабильность
- Вход больше не «зависает»: обновление токена выполняется один раз для всех запросов и идёт мимо общего перехватчика; новый токен сразу хранится в памяти, запись в хранилище ключей ограничена по времени (баг 1).
- «Нет интернета» показывается только когда устройство действительно офлайн; если недоступен сервер — отдельное сообщение. Вместо плашки — короткое уведомление о смене сети.
- Повторный запуск приложения сразу пускает внутрь по сохранённому профилю, проверка сессии идёт в фоне.
- Android: движок переживает смену сети без разрыва туннеля, проверка обновлений в фоне (WorkManager), таймер подключения не сбрасывается при перезапуске интерфейса (баги 1, 2, 4, 8).
- Задержка выбранной подключённой локации измеряется через сам туннель — одинаково для всех протоколов, включая Hysteria2 (Android — движок, Windows — Clash API sing-box) (баг 12).

### Доступ и подписка
- Каждый аккаунт получает собственный ключ доступа от сервера вместо общего зашитого в приложение; трафик считается по подписке пользователя (баг 10).
- Трафик меньше 1 ГБ показывается в МБ, обновляется раз в минуту при подключении; единицы — двоичные ГБ.
- Состояние «подписка закончилась, 7 дней на продление» с предупреждением.
- Сервер API — core.wavebreak.com.tr (напрямую, без CDN).
- Протоколы: VLESS REALITY, Direct-TLS, Hysteria2; на Android — через Xray-core.

### Поделиться и QR (баги 11, 15)
- «Поделиться» у своей подписки показывает персональный QR-код (действует 72 часа) с лимитами: устройства и общий трафик.
- Сканирование только внутри рамки; отсканированный код добавляется сразу.
- Лимит устройств проверяется на сервере: при исчерпании — «Достигнут лимит устройств». Устройство получателя видно владельцу в «Устройствах», удаление освобождает место и убирает секцию у получателя.
- Полученная подписка — отдельная секция с названием тарифа владельца, без CDN, её нельзя переслать дальше.
- В каждой секции — трафик и число устройств; карточка на главной показывает подписку выбранной локации.
- Windows: кнопки сканера нет (камера не поддерживается) — код вставляется ссылкой.

### Интерфейс и безопасность
- Убран тест пинга под кнопкой подключения (баг 5) и пункт «Авто (самый быстрый)» (баг 6).
- PIN — это и есть блокировка; смена и удаление PIN требуют текущий PIN; биометрия только вместе с PIN; повторная блокировка после 1 минуты в фоне (баг 7).
- PIN из 4 цифр больше не «молчит» на экране блокировки: проверка не зависит от зависаний хранилища ключей, неверный PIN показывается сразу.
- «О приложении» → «Веб-сайт»: https://wavebreak.com.tr (баг 13).
- Название своей секции — по тарифу (например, WAVEBREAK Fleet).

### Обновления (баг 14)
- Откат на одну предыдущую версию, если сервер его опубликовал: Android — «Настройки → Обновления», Windows — «О приложении». Повторный откат — только после следующего обновления.
