# Windows runtime dependencies

Two third-party binaries land here and get copied next to `wavebreak.exe`
by `windows/runner/CMakeLists.txt` at build time — `flutter build windows`
fails without them (`sing-box.exe not found`-style CMake errors).

## wintun.dll

Committed to this repo (small, ~420KB). From the
[WireGuard project's WinTun driver](https://www.wintun.net/) — the
userspace-visible driver DLL sing-box's `tun` inbound uses on Windows.
LGPLv2.1. Only needs replacing if sing-box's own required WinTun ABI
version changes (unlikely — it's been stable for years); if a build ever
fails with a WinTun version-mismatch error from sing-box, download the
matching build from wintun.net and drop it in here.

## sing-box.exe

**Not committed** — the repo's root `.gitignore` excludes `*.exe`
globally (same reasoning as `native/hysteria_bridge/*.aar` being
excluded on the mobile side: a large prebuilt binary doesn't belong in
git history). Fetch it with:

```powershell
# From wavebreak-pc/, PowerShell:
$version = "1.14.1"  # bump alongside sing-box's own releases as needed
$zipUrl = "https://github.com/SagerNet/sing-box/releases/download/v$version/sing-box-$version-windows-amd64.zip"
Invoke-WebRequest -Uri $zipUrl -OutFile "$env:TEMP\sing-box.zip"
Expand-Archive -Path "$env:TEMP\sing-box.zip" -DestinationPath "$env:TEMP\sing-box-extract" -Force
Copy-Item "$env:TEMP\sing-box-extract\sing-box-$version-windows-amd64\sing-box.exe" "windows\runtime_deps\sing-box.exe"
```

Or equivalently via bash/curl:

```bash
version=1.14.1
curl -sL -o /tmp/sing-box.zip "https://github.com/SagerNet/sing-box/releases/download/v${version}/sing-box-${version}-windows-amd64.zip"
unzip -o /tmp/sing-box.zip -d /tmp/sing-box-extract
cp "/tmp/sing-box-extract/sing-box-${version}-windows-amd64/sing-box.exe" windows/runtime_deps/sing-box.exe
```

Verified working with sing-box v1.14.1 (the config generated by
`windows_vpn_adapter.dart` uses a plain `tun` inbound + standard
vless/vmess/trojan/shadowsocks/hysteria2 outbounds — no bleeding-edge
feature requiring a specific newer release; any current stable sing-box
release should work, but v1.14.1 is the one actually built and tested
against this session).

The release zip also contains `libcronet.dll` and a `LICENSE` file —
neither is needed (Cronet is an alternate HTTP transport sing-box
supports but this app's config never uses) and CMakeLists.txt doesn't
copy them, so only `sing-box.exe` itself needs to land in this folder.
