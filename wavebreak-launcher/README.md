# WAVEBREAK Launcher (Windows)

Один маленький exe для любого ПК с Windows 10/11 — 32-, 64-битной и ARM64
(сам лаунчер 32-битный, поэтому запускается везде). Окно — страница
`ui.html` в Edge WebView2 (в стиле приложений: океан, волны за курсором,
стекло).

Что умеет:
- определяет систему: версия Windows и **настоящая** разрядность
  (`IsWow64Process2`: x64 / x86 / ARM64);
- показывает каталог (`catalog.go`) и рекомендует подходящее:
  **WAVEBREAK** (x64, на ARM64 — через эмуляцию) или **WAVEBREAK Lite**
  (x86); «Телефон и ТВ» — ссылка на страницу загрузки;
- для каждой программы: установлено ли и какая версия (список удаления
  Windows, Inno Setup `AppId`), последняя версия (манифесты обновлений
  `version-windows.json` / `version-lite.json` на сайте и зеркале);
  кнопки «Установить / Обновить / Открыть / Удалить»;
- скачивает установщик с прогрессом и скоростью — **только** с
  `wavebreak.com.tr` / `dl.wavebreak.com.tr` (https; переадресации наружу
  отклоняются), с зеркала, если основной адрес недоступен; запускает его
  (права администратора спрашивает Windows);
- «Связь с WAVEBREAK отсюда» — время TLS-рукопожатия до сайта, Core, API и
  зеркала загрузок, с подсказкой, если что-то недоступно.

Новые сервисы добавляются в `catalog` в `catalog.go` (продукт с манифестом и
`AppId` установщика или ссылка).

Сборка: `./build.sh` → `build/WAVEBREAK-Launcher.exe` (~7 МБ). Тесты логики
(подбор под систему, статусы, версии, разрешённые адреса) — `go test`.

Не сделано / ждёт решения:
- выкладка на сайт (`/downloads/WAVEBREAK-Launcher.exe`) — изменение
  сервера, после «ок» владельца;
- манифест Lite (`version-lite.json`) — когда Lite будет проверена на 32-бит
  Windows; до тех пор лаунчер пишет «Скоро»;
- подпись кода: exe не подписан — SmartScreen покажет предупреждение;
- значок и автообновление самого лаунчера.
- **На живой Windows не запускался** (машина сборки занята VPN владельца);
  внешний вид проверен отрисовкой страницы с тестовыми данными.
